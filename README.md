# Week 3 AI systemen

Dit is een statische website voor de Growth Map. De site bevat opdracht 1, de volledige duo-opdracht 2 met Simon en opdracht 3. Opdracht 4 is op verzoek weggelaten. Voor de site is geen buildstap, pakketbeheerder of servercode nodig.

## Bestanden

- `index.html` — de volledige website
- `styles.css` — de opmaak
- `downloads/opdracht-2-aanpak.txt` — het eerste onderdeel van opdracht 2 als los tekstbestand
- `.nojekyll` — zorgt dat GitHub Pages de statische bestanden direct publiceert

## Lokaal bekijken

Open `index.html` in een browser. De interne links werken ook als je het bestand direct opent.

## Publiceren met GitHub Pages

1. Maak op GitHub een nieuwe **public** repository, bijvoorbeeld `week3-ai-systemen`.
2. Upload **de inhoud van deze map** naar de hoofdmap van de repository. `index.html` moet direct in de hoofdmap staan, dus niet nog in een extra submap. Neem ook `styles.css`, de map `downloads` en `.nojekyll` mee.
3. Open in de repository **Settings → Pages**.
4. Kies bij **Build and deployment → Source** voor **Deploy from a branch**.
5. Kies de branch `main` en de map `/(root)`, en klik **Save**.
6. Wacht tot GitHub de site heeft gepubliceerd. Onder **Settings → Pages** staat daarna de link **Visit site**. De URL is meestal `https://JOUW-GEBRUIKERSNAAM.github.io/week3-ai-systemen/`.

Het kan volgens GitHub tot ongeveer tien minuten duren voordat een wijziging zichtbaar is. Als de site niet verschijnt, controleer eerst of `index.html` in de hoofdmap van de gekozen branch staat.

## Inhoud controleren vóór publicatie

De reflecties zijn geschreven in de ik-vorm. Controleer of ze overeenkomen met wat je zelf hebt gedaan en geleerd. De analyse van bol verwerkt de tekst die Simon heeft aangeleverd; bespreek samen of het gezamenlijke advies zijn mening juist weergeeft. De ACM-toezeggingen staan op de site als ontwerpbesluit, niet als definitief besluit.

Officiële handleiding: [GitHub Pages publiceren vanuit een branch](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
